## Conflicting evidence
- Claude hides idle rows after 30s when all idle vs omp Hub keeps parked/aborted rows visible for revive: hidden-idle declutters live view but loses dormant roster discovery; omp keeps them as parked, Claude requires next turn to reappear.
- Cursor IDLE includes recoverable run error vs Claude distinct Failed state: Cursor merges error-recoverable into idle, Claude separates Failed/Stopped — omp-style aborted/parked maps closer to Claude's explicit terminal states.
- OpenCode missing-entry=idle vs Devin explicit finished/expired states: OpenCode infers idle by absence, Devin enumerates terminal states — absence-inference is legibility-cheaper but caused stale-busy reports (claim 14).
- k9s/lazydocker use single STATUS column for binary running/exited vs agent UIs use 3+ states with animation/color/shape: infra dashboards prove single-column legibility works for binary, but agent waiting-for-human needs separate Needs-input class or it masquerades as busy.
