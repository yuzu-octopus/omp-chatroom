# F5 inter-agent protocols

## Angle

Hunt SPECS, not blog posts. For each published agent-to-agent / agent-to-client protocol record: spec version + date, transport, message model, addressing, delivery guarantee (at-most/at-least-once, ordering), and whether a shared log / blackboard is part of the spec. Target = omp chatroom plugin decision (persistent group room spanning main agent + subagents, bounded context). Primary sources only: official spec sites, spec repos, IETF datatracker. Report-only; no code.

Scope note: sibling worker owns the blackboard/claim-board angle (F6) — here blackboard is recorded only as one attribute per protocol ("is a shared log part of the spec? Y/N"), not surveyed.
