## Angle 6 — Cost and token economics of multi-agent coordination

## Claims

- multi-agent research = ~15x tokens of chat. single agent = ~4x chat tokens. src: Anthropic "How we built our multi-agent research system" (anthropic.com/research/multi-agent-research-system), pub 2025-06-13, read 2026-10-26. conf: primary/high.
- same post: Opus 4 lead + Sonnet 4 subagents beat single-agent Opus 4 by 90.2% on internal research eval. conf: primary/med (internal eval, no public replic).
- token use alone explains 80% of BrowseComp variance; + tool calls + model choice = 95%. "multi-agent scales token use past single-agent limits". same src. conf: primary/med.
- subagent pattern: worker explores tens of thousands tokens, returns 1-2k summary to lead. lead ctx stays clean but total tokens RISE. src: Anthropic "Effective context engineering" (anthropic.com, pub 2025-09-29), read 2026-10-26. conf: primary/high. KEY for room design: digest cheap for lead, expensive globally.
- Anthropic: scale effort to query complexity — 1 agent simple fact-find (3-10 tool calls), 2-4 subagents comparison (10-15 calls each), 10+ subagents only complex research. same research-system src. conf: primary/high.
- "communication tax": duplicated tokens across Planner/Reasoner/Verifier roles major inefficiency. verifier re-reads reasoning already produced. src: AgentTaxo abstract (mlanthology.org/iclrw/2025/wang2025iclrw-agenttaxo), ICLR 2025 Workshop FM-Wild, read 2026-10-26. conf: primary/med (read abstract page only, not full PDF).
- ANYMAC-Eff uses 5x fewer prompt tokens than G-Designer w/ competitive accuracy on GSM8K (95.66% full ANYMAC vs 95.07% G-Designer). within-multi-agent comparison, NOT vs single-agent. src: EMNLP 2025 paper (aclanthology.org/2025.emnlp-main.584), read 2026-10-26 via search extract. conf: primary/med (numbers via secondary extract, paper not opened full).
- Cursor SQLite swarm: workers carry >=69% tokens (90%+ mostly), but planner tokens dominate $$. Opus 4.8 planner = small fraction tokens but ~2/3 of cost; Composer 2.5 workers = most tokens, 1/3 cost. GPT-5.5 workers alone $9,373 vs hybrid worker fleet $411. total runs $1,339 (Opus/Composer hybrid) to $10,565 (GPT-5.5 all). similar quality all mixes. src: Cursor "Agent swarms and the new model economics" (cursor.com/blog/agent-swarm-model-economics), Wilson Lin, 2026-07-20, read 2026-10-26. conf: primary/high. NOTE date 2026 — post-cutoff but primary vendor source, keep.
- Cursor: planner/worker split = context efficiency, not just parallelism. planner never implements (ctx clean of detail), worker never plans (ctx all one narrow piece). same src. conf: primary/high. DIRECT support for room digest model.
- Cursor harness work cut user token costs 7% no quality loss: trim 66% sysprompt, offload rare tools (static ctx tool-def tokens -60%; MCP dynamic load -46.9% tokens in MCP sessions), cold cache miss -20% via explicit breakpoints + stable prefix, line-nos every 10th line (-1.6% cache-read toks). PLUS: subagent encouragement removed (models learn natively) + subagents carry coordination tax (dupe work, stale tasks). src: Cursor "Improved token efficiency" (cursor.com/blog/improved-token-efficiency), 2026-09-23, read 2026-10-26. conf: primary/high.
- agentic coding tasks = 1000x tokens of code chat/reasoning; INPUT tokens drive cost; same-task runs vary up to 30x; more tokens != more accuracy (peaks intermediate, saturates). models cant predict own usage (corr <=0.39, underestimate). src: Stanford Digital Economy Lab working paper 2026-04-14 (digitaleconomy.stanford.edu), arXiv 2604.22750, read 2026-10-26. conf: primary/med (working paper, coding tasks not group chat).
- prompt cache pricing Anthropic: 5m write 1.25x base, 1h write 2x, reads 0.1x (exceptions: Sonnet 5.5/Opus 5.5 0.05x, Fable 5.1 0.025x). refresh free on hit. src: platform.claude.com/docs prompt-caching, read 2026-10-26. conf: primary/high.

GPT-4.1 75% / GPT-5.2 90% NOT stated on the guide page — unverified examples, do not cite as primary. only reused prefix discounted (entire rendered prefix must match), hit not guaranteed (session reuse helps but no guarantee; per-machine entries, overflow routing, org/region isolation). explicit mode + 4-write cap verified for GPT-5.6 and later (explicit breakpoints, max 4 writes/req; earlier models implicit-only). prefix-breaking settings: model, tools (names/descriptions/schemas/ordering), parallel_tool_calls, text.format, reasoning.effort, text.verbosity, context_management/compaction. src: developers.openai.com/api/docs/guides/prompt-caching + openai.com/index/api-prompt-caching, read direct 2026-10-26. conf: primary/high on mechanics; primary/low on GPT-4.1/GPT-5.2 % (not on page).

## Conflicting evidence
- Cursor 2026-09 says subagents REDUCE token spend (fresh ctx window) vs Anthropic 2025-09 says subagents INCREASE total tokens (tens of k explored per 1-2k returned). reconcile: both true at different level — subagent isolates PARENT ctx (Cursor view, per-agent spend down) but ADDS worker exploration tokens globally (Anthropic view, system spend up). room digest same: cheap for reader, expensive system-wide. report both, not either/or.
- "15x" Anthropic figure = vs chat, not vs single-agent on same task. do NOT cite as multi-vs-single multiplier.
