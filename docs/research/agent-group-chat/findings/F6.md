## Conflicting evidence
- Cursor 2026-09 says subagents REDUCE token spend (fresh ctx window) vs Anthropic 2025-09 says subagents INCREASE total tokens (tens of k explored per 1-2k returned). reconcile: both true at different level — subagent isolates PARENT ctx (Cursor view, per-agent spend down) but ADDS worker exploration tokens globally (Anthropic view, system spend up). room digest same: cheap for reader, expensive system-wide. report both, not either/or.
- "15x" Anthropic figure = vs chat, not vs single-agent on same task. do NOT cite as multi-vs-single multiplier.
